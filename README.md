# Ranj Solar Panel Website

## GitHub Pages
1. Create a new GitHub repository, for example `ranj-solar-panel`.
2. Upload everything inside this folder (keep the `assets` folder).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you the public website address.

## Adding more gallery photos

Put new photos inside `assets/`, then copy one of the `.gallery-card` blocks in `index.html` and change:
- `data-image="assets/your-photo.jpg"`
- the image `src`
- the Kurdish/English/Arabic title values

The gallery opens images in a mobile-friendly lightbox with previous/next buttons and keyboard arrows.
